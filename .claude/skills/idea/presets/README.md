# Presets

A preset is a head start for a common kind of app. The grill asks which one the idea is closest to, loads it, and **confirms** the preset's answers instead of asking from zero. Anything the person changes wins. Pick one in the "who and why" topic.

| Preset | For |
|---|---|
| `saas` | Paid software people sign up for: accounts, plans, billing |
| `internal-tool` | A tool for one team or company: sign-in, roles, data tables, no billing |
| `content-site` | Marketing site, portfolio, blog or docs: fast, public, no accounts |
| `marketplace` | Two sides (buyers and sellers, hosts and guests) and payments between them |
| `api-service` | A backend or AI service other apps call: keys, rate limits, no UI |

No good fit? Skip presets and grill from scratch.
