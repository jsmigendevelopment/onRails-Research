# Preset: Content site

**For:** a marketing site, portfolio, blog or docs.

## Preloaded (confirm, don't ask)

- **Add-ons:** Cloudflare Web Analytics, Turnstile on any form.
- **Floor answers:**
  - no accounts;
  - prerendered pages;
  - a performance budget aimed at Lighthouse 100;
  - full SEO (titles, share images, a sitemap, structured data);
  - a contact form that's spam-protected and doesn't auto-reply;
  - WCAG 2.2 AA.
- **Common slices:** the home page, the content pages, the contact form, SEO and share images.
- **Skip:** the layered API for a single form. One server function over a plain handler is enough.

## Still ask

- Who it's for and the one action a visitor should take.
- Where content is edited: in the repo (Markdown) or in a CMS.
- Brand, tone and any visual references. Ask this open first.
